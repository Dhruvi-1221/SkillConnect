Software Engineering Project Documentation

SkillConnect

Full-Stack Student Talent Marketplace & Portfolio Social Platform
Project Overview: SkillConnect is a production-grade full-stack web application built using Python 3.13, Django 5.2, MySQL 8.0, HTML5, CSS3, and Vanilla JavaScript. It connects verified student freelancers with campus and local clients with milestone tracking, direct chat, and community reviews.

3. Complete File-by-File Guide

Project Configuration

  • manage.py: Django command-line management utility for running the server, migrations, and tests.
  • skillconnect/__init__.py: Initializes PyMySQL as the MySQLdb driver so Python 3.13 communicates smoothly with MySQL on Windows.
  • skillconnect/settings.py: Project settings including database configuration, custom user model, and static/media directories.
  • skillconnect/urls.py: Master URL router combining all 10 application routes.
  • populate_db.py: Automated seeder script populating 12 categories, 8 users, student profiles, posts, services, and orders.

Application Modules

  • accounts/: Custom User model with roles (CUSTOMER, STUDENT, ADMIN), StudentProfile with college ID upload, and social following.
  • posts/: Visual portfolio posts, likes (AJAX), and comments.
  • services/: Freelance service packages, turnaround times, and pricing in INR (₹).
  • orders/: 5-stage milestone order tracker (REQUESTED → ACCEPTED → IN_PROGRESS → READY_FOR_REVIEW → COMPLETED) with audit history.
  • chat/: 1-to-1 direct messaging system with 3-second live AJAX polling.
  • reviews/: Verified client 5-star ratings and written feedback for completed orders.
  • reports/: Content flagging and user moderation system.
  • notifications/: Real-time user alert notifications for orders, messages, and approvals.
  • admin_panel/: Custom dashboard for campus admins to review student ID cards and moderate the platform.
  • core/: Homepage landing view, multi-model global search, and automated test suite.

5. Step-by-Step Functional Workflow

  1. Registration: User registers as a Student or Customer. Passwords hashed with PBKDF2-SHA256.
  2. Student Verification: Student enters college details and uploads an ID card. Admin reviews and approves it, awarding the ✓ Verified Student badge.
  3. Portfolio & Services: Student publishes creative work and sets fixed-price services in INR (₹).
  4. Booking & Tracking: Customer requests a service. Both parties track progress through a visual 5-stage milestone stepper.
  5. Direct Chat: Customer and student chat in real-time with automatic 3-second polling.
  6. Reviews: Upon project completion, customer leaves a verified rating and review.

6. Key Viva / Exam Questions & Answers

QuestionExaminer-Ready Answer
Why MySQL over SQLite?MySQL is a production-grade relational database with true multi-user concurrency, transactional integrity (ACID), and robust foreign keys.
How is CSRF prevented?Django generates a unique CSRF token per session. Every POST request and AJAX call must supply this token or be rejected.
How does student verification work?Students upload an ID image. Admins review it via a dedicated admin portal. Approving updates the status to VERIFIED and triggers the verified badge.
How does live chat function without WebSockets?It uses Vanilla JavaScript AJAX polling every 3 seconds, fetching only messages where id > last_id. This is reliable, lightweight, and requires no Node.js server.
